Flyte SDK — real browser client

Local UI on localhost.<your-admin-host>, API calls go to your Flyte endpoint (console-style local dev).

Setup (see repo .env.example):
1. /etc/hosts: 127.0.0.1 <FLYTE_DEMO_HOST>
2. brew install mkcert && mkcert -install (once)
3. Copy .env.example → .env and fill in values
4. pnpm demo:client

Open https://<FLYTE_DEMO_HOST>:8080 

Ready. Configure .env then pnpm demo:client.
